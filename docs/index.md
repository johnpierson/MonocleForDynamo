# Monocle is a fully open source view-extension for the [Dynamo Visual Programming environment](https://dynamobim.org/).

## Supported Dynamo versions
Monocle is actively developed for Dynamo 3.0 through 4.2. Builds for Dynamo 2.0 through 2.19 are frozen: they still install and work, but no longer receive fixes or new features.

## Available Tools
- **Package Usage** — see which packages a graph depends on, annotate nodes with their source, copy the list to the clipboard
- **Custom Node Identifier** — highlight custom nodes (`Ctrl+Alt+H`), reset highlights (`Ctrl+Alt+R`), reveal graph inputs (`Ctrl+Alt+I`)
- **FOCA** — the in-canvas widget on the selected node
  - Alignment and distribution (also `Alt` + arrow keys)
  - Colour-coded grouping
  - Pow List and Fundle Bundle
  - Combinifier
  - Dropdown Converter 3000
  - Node Swapper
- **Node Swapper** — a paintbrush that replaces nodes and rewires them
- **Graph Resizerer** — rescale a graph authored at a different node scale
- **Inline Node Connect-o-matic** — drop a node onto a wire while holding left `Alt` to splice it in (off by default; enable it in the monocle menu)
- **Simple Search** — an alternate node search in the sidebar (`Ctrl+F`) or in the canvas (`Shift+Space`)
- **Standard Views** — Front/Back/Left/Right/Top/Bottom camera buttons in the 3D view's status bar
- **Fancy Paste** — paste without wires (`Ctrl+Shift+V`), in Dynamo's Edit menu
- **Better Save** — Quick Save with a timestamp (`Ctrl+Alt+S`), Sloppy Save, and Quick Graph Thumbnail, in Dynamo's File menu
- **Graph Information Template** — drop in a pre-populated metadata group
- **Mega Ultra Node Documenter** — export documentation images for a node
- **Custom Settings** — group colours and text, custom-node highlight colour, note prefix, save/load presets
- **UI Conformity for Revit** — undoes the theme DevExpress-based add-ins force on Dynamo
